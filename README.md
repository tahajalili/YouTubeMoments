# YouTubeMoments

A small Manifest V3 extension (Brave/Chrome) for saving timestamped notes and bookmarks on YouTube videos.

## Install
1. Open `brave://extensions` and enable **Developer mode**.
2. Click **Load unpacked** and select this folder.

## Use
- On a YouTube watch page, press **Option/Alt+N** or click the 📝 button (top-right). The video pauses.
- Type a note and press **Enter** (empty note = bookmark). Click a timestamp to jump to it.
- The toolbar icon opens a searchable list of all notes.

Notes are stored locally in `chrome.storage.local`.
